# 财务公式与模型边界

所有数值运算在 Python Decimal 中执行，公式位于 backend/src/company_research/financials/formulas.py。输入、输出、单位、期间、公式版本和 input_refs 保存到 CalculationResult。Reviewer 根据同一注册公式复算并核对引用值。

|指标|定义|
|---|---|
|YoY|当期 / 上期 − 1|
|comparison_delta|本期 − 可比期，同单位|
|percentage_points|(本期比例 − 可比比例) × 100，输出 percentage_points|
|segment_share|分业务收入 / 合并收入，同币种/单位/期间|
|CAGR|(终值 / 起值)^(1/年数) − 1；起终值和年数为正|
|毛利率|(收入 − 成本) / 收入|
|净利率 / 营业利润率|净利润或 EBIT / 收入|
|ROE|净利润 / 平均股东权益|
|ROIC|EBIT × (1 − 税率) / 平均投入资本|
|资产负债率|负债 / 资产|
|流动 / 速动比率|流动资产 / 流动负债；(流动资产 − 存货) / 流动负债|
|存货 / 应收 / 资产周转|成本 / 平均存货；收入 / 平均应收；收入 / 平均资产|
|FCF|经营现金流 − 资本开支|
|EPS|同口径净利润 百万元 / 股本 百万股|
|PE|股价 / EPS；EPS 非正不使用|
|PB|股价 × 股本 / 股东权益|
|EV/EBITDA|(股价 × 股本 + 有息负债 − 现金) / EBITDA|

平均值需有真实数据或明示计算依据；不得把期末值直接当平均值。所有缺失、冲突、零分母和单位不一致抛错。历史计划可通过 inputs 显式引用 metric@period 与 formula:id；依赖图展开、去重且禁止循环。股价时点由来源描述，季度不能替代年度。

## 五种收入模板

volume_price：销量 百万件 × 单价 元/件；capacity_utilization：产能 百万件 × 利用率 × 单价；users_arpu：用户 百万人 × ARPU 元/用户；market_share：市场规模 百万元 × 份额；growth：上期收入 × (1 + 增速)。输出统一百万元。分部成本按来源支持的成本比例计算，可替换为独立成本公式。假设按业务、情景、期间保存，包含 rationale 与 evidence_ids。

## 三表联动

分部收入/成本汇总 → 毛利 → 期间费用 → EBIT → 平均债务利息 → 税前利润 → 正利润税费 → 净利润。期间费用与成本已包含折旧，现金流加回同一折旧假设。固定资产期末=期初+资本开支−折旧。

营运资本=应收+库存−应付；经营现金流=净利润+折旧−营运资本增加。投资现金流=−资本开支；融资现金流=新增借款−还款−分红。期末现金=期初现金+CFO+CFI+CFF。债务期末=期初+借款−还款；权益期末=期初+净利润−分红。其他资产负债显式保持期初数值，不作为平衡项。

校验期初及期末资产=负债+权益、现金变化、分部收入和成本合计，固定资产/债务/现金非负。现金不足必须新增有依据的融资假设后重算。Bear/Base/Bull 独立滚动，预测期间标 E。目标价=预测 EPS×有依据的目标 PE，示例倍数完全合成，无真实价格意义。

## 当前适用边界

适合具有清晰经营分部的非金融企业简化预测；不自动建模银行、保险、复杂租赁、少数股东、递延所得税、其他综合收益、并购资产、库存减值或多币种。原始材料必须明确利润归属、股本及财务口径。缺少驱动数据或假设依据可以输出明确受限研究；关键历史数字或证据缺失、三表错误不能通过终审。

## v1.1 同比成稿规则

comparisons.py 独立构建 ComparisonResult，保留两期 fact_id、来源位置、金额、增减额、比较类型、状态与注册计算引用。核心为营业收入、营业成本、归母净利润、扣非归母净利润、经营现金流；合并净利润不替代归母，扣非不由利润推算。展示三个完整财年并额外取得前序年，中期与上年同长度累计/单季度期间比较。年度与中期分别成表，实际值不混预测。

正基数使用普通同比；40→−10 同时展示 −125% 和转亏。负基数不用普通增长率，−100→−60 标亏损收窄 40；现金流用净流入/净流出状态。零基数仅展示金额变化与百分比不适用。比例变动用百分点，30%→32% 为 +2。较上年末变化须显式 year_end_change，不能标中期同比。未证实的币种换算被拒绝；ROE/ROIC/PB 非正权益/投入资本标不适用，不产生误导比率。

财务小节表格与正文由同一结构化结果绑定；正文分别说明每个核心指标的实际数值、方向与同比/状态。有证据支持的原因由块写作补充；否则明确驱动原因尚未确认。core_gate 复建比较与公式、核对五小节、来源字段与必需正文；缺项不能降 warning/limited，定向补查/修复耗尽后 blocked，API/导出再次检查。金额展示至少两位，极小变化增加精度（当前上限 16 位）；不是供应商 tokenizer 或无限精度排版。
