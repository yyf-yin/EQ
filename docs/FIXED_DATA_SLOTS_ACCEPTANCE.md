# 固定表取数实施与验收

## 实施范围

真实研究默认使用 `fixed-slots-2`。固定字典见 [表设计](FIXED_DATA_SLOTS_DESIGN.md) 和 [字段 JSON](fixed_data_slots.v1.json)，运行时副本位于 `backend/src/company_research/templates/fixed_data_slots.v1.json`，随 Python 包分发。共七区、133 个原始字段；年度、季度、业务、债券、产品数量只改变记录数。plan 不再设计财务字段，也不生成动态财务取数任务。新增当年最新期间与上年同期门槛，详见 [季度数据槽](QUARTERLY_DATA_SLOTS.md)；下方旧验收记录保留其原验证范围。

执行路径：上传年报确认证券身份 → 确定年报年度与真实业务 → 固定槽实例化 → 指定年报提取 → 固定计算依赖 → 公司/业务/行业资料槽 → 历史分析与适用的预测 → 写作审核。分析用的固定问题框架保留，取证不再按这些问题逐一搜索。

公司全称和证券代码优先来自本次上传年报，其他证券字段来自 local-datasource；财务和债券仅来自用户为本次研究上传的公司年报及一并提供的更正披露。本地目录年报不自动纳入，搜索结果中的年报不作为补充。未上传文件不创建真实研究任务；已上传文件但没有本公司年报时，范围识别前明确提示，不调用模型编造范围或 web 补财务。个人工具不新增资料质量评分和重复人工确认，保留读取、主体/年度分流、原文/列头/单位与口径检查。见 [用户年报入口](USER_ANNUAL_REPORTS.md)。所有股票股数明确注明单位，价格携带交易日；不采纳晚于研究快照的价格。

年报值经过一次原文、数值、年度列、单位及范围的提取检查即锁定。多年表可引用独立表头，不受旧的可信域名/单年度短摘录规则限制。低优先级候选不会覆盖锁定值或创建人工问题。数据库拒绝修改终态槽及同 ID 原始事实。原值与规范值分开；确定性派生值独立保存并标记 `value_origin=derived`。

## 去重与停止

- 公司年报同一内容窗口的提取结果按任务保存，独立于随机任务 ID 和分析问题；财务提取同时保留业务行业定性证据。
- 后续窗口只请求尚未完成的固定目标，不再要求模型提取已锁定的收入等数值。
- 首次请求在发送前持久化；部分入库中断后复用已提交模型输出与首次锁定时间。失败修复只发送失败字段与原文，不重复处理成功字段。
- 一个公司、业务或共享行业一个资料槽；相同行业可关联多个业务。通用预设资料方向加模型补充中性大方向，不为每个方向或分析问题分别建立检索任务。详见 [业务行业资料收集](QUALITATIVE_COLLECTION.md)。
- 先使用已提取年报证据及已有参考资料。默认每槽一次宽范围 web 搜索加最多两次按缺口分组补查，最多阅读八份不同资料。适用方向已覆盖、达到预算、重复查询或连续补查无新增有效证据时停止；已有成功提取在本次研究内复用。
- 资料覆盖只评估新增证据，沿用已有覆盖；ready/limited 均关闭该轮取证。预设方向允许部分取得、限定检索未找到、不适用和获取失败。关键机制可分析且限制清楚时，可选方向缺口不强制阻断。未检索为待收集，没搜到不能认定无变化。明确无变化须有原文证据并限定事项和期间。不建设跨研究本地资料库。
- `not_disclosed`、`not_applicable`、`source_missing`、`extraction_failed` 分开。空白和破折号不自动填零。只有明确不存在的组件可在计算层贡献零，原始槽仍无虚构数值。
- 原始数据导致的不可修复审核问题直接阻断，不重复运行取证和规划。写作等可修复问题仍保留原有审核机制。

## 本地资料合同

推荐证券主档为 JSON/CSV/XLSX，每个主体/证券一行：

```json
{
  "company_id": "EXAMPLE",
  "company_name": "示例非金融公司",
  "ticker": "000123",
  "exchange": "SZSE",
  "security_type": "stock",
  "financial_company": false,
  "quote_currency": "CNY",
  "price": "10.00",
  "price_unit": "CNY/share",
  "quote_date": "2026-10-13",
  "shares": "20",
  "shares_unit": "million_shares",
  "shares_effective_date": "2026-01-01",
  "multi_class_listing": false
}
```

此例完全虚构，仅说明字段结构。证券代码使用文本保留前导零；股数单位必须声明，不能猜测为股、万股或百万股。

通过初始页“添加文件”选择并上传本次使用的 PDF、DOCX、TXT、MD 等年报；放入本地资料目录不会自动采用。文件名/报告开头应能识别为本公司年报；扫描件须有可读取文本。已有年报结构化副本也可上传使用：

```json
{
  "document_type": "annual_report",
  "company_id": "EXAMPLE",
  "report_period": "2025A",
  "segments": ["业务A"],
  "facts": [
    {
      "field_id": "income.revenue",
      "period": "2025A",
      "value": "1234567890.00",
      "unit": "CNY",
      "scope": "consolidated"
    },
    {
      "field_id": "segment.revenue",
      "period": "2025A",
      "segment_id": "业务A",
      "value": "1234567890.00",
      "unit": "CNY",
      "scope": "segment"
    }
  ]
}
```

`document_type=annual_report` 表示明确指定的年报结构化副本，不能用它把研报/API 估计值冒充年报事实。仍应保留原年报供追溯。支持既有 `metric_code` 的确定映射，但没有年报标记的普通财务 JSON 不进入原始财务表。金额与精确股数优先用十进制字符串，避免浮点精度损失。

默认三个展示财年加一个前序年。年报版本和各年度来源在填槽前冻结；有对应年度原表时不随意拿另一年报的比较列替换。重述、币种或范围不兼容导致无法比较时保留原值和限制，不自动改数。

## 展示、导出与恢复

新增只读 `GET /api/research/{run_id}/data-slots`；进度接口返回固定槽和业务行业槽统计。前端展示七区的年度矩阵、原始单位、终态、来源位置及多产品经营明细；债券未知不会显示为无债券。

阶段成果/评估包增加 `data_slot`、`collection_slot`、`slot_calculation`、`fixed_derived_fact` 和 `bond_presence`。读取这些成果不调用模型。模拟模式以原有合成 Fixture 投影同一表结构，所有数值均标为模拟，不要求虚构未提供字段。

模板、取数模式及提示进入续跑兼容性检查。更新后应重启前后端并创建新研究；旧任务和评估包保留，旧断点不会自动套用新取数规则。`data_collection_mode=legacy` 仅保留旧协议回归路径，默认新真实研究为 fixed。

## 计算边界

固定历史计划启用毛利率、净利率、归母 ROE、周转、偿债及现金资本开支代理口径的 FCF；输入缺失则该指标不可用。平均余额、有息债务、其余资产负债及折旧摊销按固定依赖派生，不另开取数问题。没有完整债务组件不猜测债务合计。

EBIT/EBITDA/ROIC 的完整政策尚未定义，因此不允许模型自由补数启用。购建长期资产现金只作为明确标注的资本开支代理值。现有三表预测是简化模型；缺关键输入、分部非完整互斥合计、已知少数股东或复杂租赁等情形关闭对应预测，保留可交付的历史与业务分析。证券多类别股份与历史/未来股本口径不能自由混用。本次没有扩大为银行保险或完整复杂会计模型。

## 验证

新增固定表测试覆盖：133 字段展开；本地证券和年报导入；共享行业；终态重放；锁定值不可覆盖；多年表头/单位；错误年度列有界修复；缺年报不 web 补数；资料槽有界搜索；原值与锁定信息的 API/导出；受限报告批准交付；研报不冒充年报；明确不存在的债务组件；不同任务不复用；部分提交恢复；真实 Gateway 的模拟 HTTP 完整流程。新资料合同的覆盖和状态测试见 QUALITATIVE_COLLECTION.md。

前端测试覆盖真实零值、未披露、债券未知及多产品单位分列。验证均使用本地合成资料、脚本模型或 Mock HTTP，不证明真实供应商质量或实际节省比例；没有调用真实模型/搜索服务进行公司研究。
