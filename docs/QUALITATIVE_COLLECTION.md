# 业务与行业资料收集合同

本次实现 `materials-2`，沿用 `fixed-slots-1` 的财务和证券合同。年报入口已收紧为 [仅由用户上传提供](USER_ANNUAL_REPORTS.md)；复用用户年报已提取的业务证据，业务行业仍可使用已有其它参考材料和 web 搜索。不会为补充资料主动寻找年报，已识别的年报搜索结果在读取前排除，正文识别出的非用户年报不进入提取。不新建本地资料库，不做跨研究的文档或行业知识复用。

## 范围与方向

一个公司整体槽、每个实际业务一个业务槽、每个共享行业一个行业槽。共享行业的范围与证据可关联多个业务，避免重复收集。

| 资料包 | 通用预设方向 |
| --- | --- |
| 公司整体 | 公司身份与业务构成、经营变化与布局、治理与经营约束 |
| 业务 | 产品与经营模式、经营变化与布局、经营驱动与约束 |
| 行业 | 行业边界与口径、市场规模与结构、需求与供给、竞争与产业链、政策与监管变化、技术与产品演进、行业约束与风险 |

预设方向是覆盖检查类别，不是分别发起的检索任务。模型基于实际业务、行业范围和已经获得的证据，每槽最多补充三个中性方向，例如支付与采购机制、资源条件、贸易规则与海外布局。方向须包含说明和适用理由，可以不补充；程序拒绝重复标签、空白方向及明显带结论/疑问倾向的标签和说明，例如“近期利好政策”“能否成为增长点”；也拒绝把股价、证券代码、三表、预测和估值取数加入定性补充方向。语义是否适用仍需要模型依据证据判断，关键词过滤不等于完整语义校验。

规划是一个持久化步骤，通常一次模型请求覆盖全部槽；槽数超过配置容量时按容量分批。预设范围、模型补充及任务身份在本次研究内冻结，续跑复用已保存输出，不因后续增加证据而重新规划大方向。

一般资料期间从最早展示财年开始，截至 brief.as_of（未提供时使用研究创建日）；政策变化默认回看三年。地域不由程序猜测，按实际材料披露判断，未明确时保留限制。来源日期晚于研究时点的已知资料不进入本次覆盖检查；未知/非标准日期交给模型明确判断，不自动猜测。

## 收集与停止

执行顺序：已有年报证据 → 本次已有参考材料 → 一次宽范围发现 → 按重要缺口分组补查 → 关闭资料槽 → 分析。

首次搜索覆盖整个资料包，补查按尚未取得/部分取得的方向分组，每组最多三个方向，关键机制优先。查询由程序依据主体、期间和中性方向生成，不使用分析问题或预设观点。默认每槽最多三次搜索（一次发现、两次补查）、八份不同正文材料；政策和市场规模没有材料时不强制全部填满。

同一内容规范化后在本次运行内复用提取结果；不把同一份材料按不同方向重新提取。相同查询通过运行内持久化执行单元复用；重复查询、连续两次搜索没有新增被采用的证据/有效覆盖、搜索或正文预算用完，均停止。结构化证券和已锁定的年报数字行不消耗定性正文预算，不得通过行业资料改写财务槽。

覆盖评估只发送新证据，携带标题、来源、发表时间和位置，并合并此前有效覆盖。数份材料可组成一次评估；超长引文使用标记的部分摘录，完整原文保留在本次证据记录中。无法容纳基本评估上下文时明确报容量错误，不能记为“未找到”。多个业务的共享行业资料及缺口均进入对应分析上下文，状态变化影响分析/写作缓存版本。

搜索结果在读取前保存，历史中记录是否已经处理；中断后先处理已取得结果，复用成功的提取及模型输出，再决定是否补查。终态 ready/limited 不会因复跑或写作审核重新开启。

## 覆盖状态

| 状态 | 含义 |
| --- | --- |
| pending | 尚未完成适用资料检查或该范围没有执行搜索，不能说已搜索未找到 |
| found | 有可追溯适用证据支撑该方向 |
| partial | 仅部分范围/期间/地域有证据 |
| not_found | 该方向已执行限定搜索，未取得可采用证据；不代表不存在 |
| no_change | 原文明确支持某项事项维持原状，引用已知证据并说明具体事项和期间 |
| not_applicable | 与本次范围无实质关联，须有解释 |
| retrieval_failed | 相关请求、正文读取或提取失败，不能据此认定没有资料 |

程序检查证据身份、无变化原文表达及适用理由，模型负责语境、口径、事实/管理层观点/机构预测的区别。不能因为没有搜到政策变化，就写“政策无变化”；不能因为没有市场规模资料，就写“市场小”。

关键经营/行业机制有证据且覆盖评估认为可以分析时，槽可标 ready；可选方向仍允许缺口，限制随资料包交给分析。关键机制不足则为 limited，也结束本轮收集，不换词无限搜索。财务核心输入仍遵循独立的固定表门槛。

## 配置与展示

| 环境变量 | 默认值 | 范围 |
| --- | --- | --- |
| CDR_MATERIAL_SEARCH_BUDGET | 3 | 0–6，0 表示不搜索 |
| CDR_MATERIAL_DOCUMENT_BUDGET | 8 | 1–30 |
| CDR_MATERIAL_EXTRA_DIRECTION_LIMIT | 3 | 0–5，0 表示只用预设方向 |
| CDR_MATERIAL_POLICY_YEARS | 3 | 1–10 |

前端资料槽显示期间、预设/模型来源、补充理由、逐方向状态、证据 ID、限制、搜索记录和停止原因。`data-slots` API、阶段成果 JSON/ZIP/Markdown 导出均保留资料方向与覆盖，不暴露内部搜索恢复收据。

新提示、方向模板、收集合同与配置进入恢复兼容性检查。更新后重启服务并创建新真实研究；旧成果保留，旧断点不套用新合同。模拟模式继续使用原有合成资料路径。

离线测试覆盖：预设和中性补充/数量上限、规划冻结、共享行业关联、可选缺口交付、未搜索与未找到区别、无变化原文验证、未知证据拒绝、请求失败、增量评估、相关性筛选、分组补查、终态复用、搜索读取中断恢复、镜像正文复用、容量分批与长引文、未来来源排除、阅读和搜索预算、分析缓存变化以及公共导出字段。

既有固定表与模拟 HTTP 流程继续验证财务锁定、分析、报告交付和恢复合同。前端验证预设/补充及状态区别。本次不调用真实模型和搜索供应商，不据此声称真实覆盖质量或节省比例。
