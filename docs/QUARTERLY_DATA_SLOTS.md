# 季度与当年最新期间数据槽

真实固定模式使用 `fixed-slots-2`、`uploaded-quarterly-periods-1`。保留七区 133 个原始字段，并按年度、季度／中期、业务展开。

## 期间与来源

| 编码 | 流量范围 |
| --- | --- |
| 2026A | 2026 全年 |
| 2026Q1 | 1–3 月累计 |
| 2026H1（输入 Q2 归一到 H1） | 1–6 月累计 |
| 2026Q3 | 1–9 月累计 |
| 20261Q / 20262Q / 20263Q / 20264Q | 对应单季度 |

利润表和现金流量表保存期间发生额；资产负债表保存期间末余额，并附起止日期和期间类型。单季与累计不能混用；年报分季度表只填单季槽，不当作全年数或半年累计数。原始槽不根据累计数差额推算。

年报、季报、中报和更正披露都只使用本次上传文件。本地目录和 web 公司财报不能补入财务槽。上年同期可由本期财报比较列提供，不强制上传独立的同期文件。季报的上年末资产负债余额不能冒充上年同季余额。

上传结构化 JSON/CSV/XLSX 副本时，财报类型使用 `annual_report`、`quarterly_report`、`interim_report` 或 `semiannual_report`。`report_period` 标明整份财报期间，`period` 标明每条事实期间，例如一份 `report_period=2026H1` 的中报可以同时提供 `period=2026H1` 和 `period=2025H1` 的数据。保留明确的 `company_id`、固定 `field_id`、单位和合并／分部口径；结构化副本不得将机构预测冒充财报原始值。

## 当年必需与历史可选

以研究创建日期为截止日，从上传的本公司季报／中报确定当年最新已披露累计期间。例如最新为 2026H1，则 2026H1 与 2025H1 的核心字段均必需：营业收入、营业成本、归母净利润、扣非归母净利润、经营活动现金流量净额。两期通过年度列／期间、数值、单位及会计范围检查后才锁定并计算同比。零基数、负基数沿用已有比较规则，不强行给百分比。

没有当年季报／中报，或最新期间／上年同期核心字段缺失，保留阶段成果并阻止正式计算／交付；不自动换渠道补数。不会因为最新报告字段缺失而退回较早报告。

展示财年、同比基期及研究当年的已结束季度创建可选槽。更早年度没有相应披露时保留空值和缺失状态；不填零，不将历史季度缺口设成核心阻断。业务收入、成本和披露的分部利润也按期间展开，未披露的业务数据仍允许留空。已知发表日晚于截止日、或报告期尚未结束的资料，不参与最新期间选择。

## 展示与恢复

固定表可切换年度、季度／中期累计、单季度；显示当年最新期间、同比必需标记、期间范围及缺失原因。API 与阶段成果导出保留期间元数据；正式报告核心同比表同时包含年度和最新累计期间。

合同、字段模板和提示已升级。更新后重启服务并创建新研究；旧任务成果保留，旧断点不能混用新规则。模拟模式继续沿用合成示例。
