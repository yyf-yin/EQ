# 断点续跑首版实施与验收

当前规则更新：2026-10-12。以下当前规则优先于后面的历史验收记录。

## 当前继续规则

- 启动器在服务就绪后、浏览器打开前检查最近创建且未完成、未选择放弃的任务，在 CMD 提示 Y/N；大小写均接受，非法输入重新询问，没有候选任务则不提示。
- Y 仅接入选中的原 run_id，读取其最近图检查点和校验有效的成功单元；其他旧任务仍禁止前端继续。N 返回初始页面，不新建或执行任务，保留旧成果并记录放弃决定，旧任务以后不重复提示。
- 选择绑定本次服务会话与启动候选 ID；重复提交幂等，只能选择一次，不能换成更早的任务，也不能在候选过期后使用旧选择。服务重启默认不调度任何旧任务。
- 隔离、规则、图检查点文件、模型和资料配置、预算仍检查。安全检查失败的 Y 返回原因并重新要求选择，不能回退拼接其他任务。预算不足但其他检查通过时接入暂停态，在前端调整预算后继续。
- 当前程序中的暂停、断网或执行中断仍可在前端继续；浏览器刷新或断线不改变服务会话。真实质量阻断不开放继续，仅明确修复的旧发布日期元数据误阻断可经启动 Y 选择和隔离检查恢复。
- 前端在 Y 时自动打开 CMD 选择的原任务；N 时清除浏览器旧任务缓存并显示初始页面。等待启动选择结果后才加载任务，同一服务内后续手动创建任务、刷新页面不会切回启动任务。暂停/继续按钮有请求反馈，保存期间禁用继续。
- N 返回首页修复验证：启动选择专项 17 项通过（`work/startup-n-regression/results.xml`），包含 Windows PowerShell 实际输入、重复 N 的幂等行为、旧成果保留及不创建/调度任务；前端 26 项通过并完成生产构建，覆盖缓存清除、首页刷新、手动创建后刷新及启动响应延迟。使用独立数据库和模拟模式。
- 验证：启动选择与恢复/隔离联合 62 项通过（`work/startup-choice-results.xml`）；补充原发布日期误阻断和放弃任务排除后，启动及研究接口 19 项通过（`work/startup-final-results.xml`），包含 Windows PowerShell 实际输入 Y/N、非法输入重试和模拟后端启动。前端 17 项测试、生产构建及 6 项浏览器实测通过；另 2 项依赖额外故障样例的浏览器测试跳过。均使用独立数据库、模拟模型和搜索，测试服务已关闭，未修改真实任务的状态或替用户做启动选择。

## 历史首版验收（2026-10-11，无确认的重启恢复已取消）

## 实际实现

- 同页暂停、继续、失败续跑、预算调整；原 run_id、事件、引用及成果保持。终态恢复会重新连接 SSE/轮询，历史事件去重保留。
- pausing 状态停止新工作，让已发请求提交完整结果，最长收尾 60 秒；排队任务直接暂停。主动暂停/正常退出后不被启动调度；崩溃遗留 running 继续原图。单 worker 下通过数据库条件更新和任务身份校验防止重复调度。
- 新 execution_units/execution_meta/execution_attempts 表记录单元与执行历史。主图保存节点增量，Researcher 独立保存检索、提取、压缩及完整任务结果，成功同伴不因一项失败丢失。块依赖只在该块所有任务完成后释放。
- 所有真实 Gateway 结构化输出按执行作用域、模型身份、完整消息和 schema 保存；因此预测各情景/年度、写作草稿/反思/修订、各角色/章节语义审核以及拆分子请求可以独立复用。已有批次、分析块及章节缓存保留。
- 单元成功输出带校验和；输入、循环/任务实例不同不会仅按节点名命中。业务提交后、图提交前故障可重放已保存单元。图采用同步 durability，完成事件按实例幂等提交。
- 模型请求发送前保留原有持久预算预留；成功/截断等有 provider usage 的调用按实测用量重建累计预算，未返回用量保留估算。重启后 running 请求标为 uncertain，角色累计统计从历史调用恢复。
- 预算调整在一个 SQLite 事务内保存总限额、任务专用角色块上限覆盖和调整记录。显式提高每块上限可解除 models.yaml 对本任务的旧角色块限额，不修改全局模型文件。
- 导出写隔离临时文件后原子替换，保存报告快照/文件校验和；已成功且有效的格式复用。取消中的后台渲染线程无法覆盖正式文件；正式交付仍校验当前批准快照。
- `start.ps1` 正常关闭前请求 pause-active，等待保存后停止本次服务。辅助验证脚本独立使用 mock、8014/5184 端口、work/resume-browser 数据库。

## 接口

| 方法与路径 | 行为 |
| --- | --- |
| POST /api/research/{id}/pause | 返回 202，停止新工作并保存进度；重复请求幂等 |
| POST /api/research/{id}/cancel | pause 的兼容别名 |
| POST /api/research/{id}/resume | 返回 202；接受 interrupted/failed 及预算造成的 blocked；运行/排队中的重复点击不产生新执行 |
| GET /api/research/{id}/recovery | 只读恢复位置、保存计数、预算、未知调用、可继续条件 |
| POST /api/research/{id}/budget | 三个必填字段 global_call_budget/global_token_budget/block_call_budget；只增加任务总限额，不自动继续 |
| POST /api/research/pause-active | 本地启动器关闭前收尾；无生产故障注入能力 |

GET 状态同时返回 recovery。恢复前检查原资料、提示、模型与研究/修复参数指纹；密钥更新、预算提高及执行并发调整不使内容失效。模型、提示、资料变化暂要求恢复原配置或新建任务，避免旧图直接进入交付。

## 保证边界与后续扩展

### 来源发布日期误阻断修复（2026-10-12）

- 搜索结果可能给同一正文返回不同标题或发布日期。这些字段不再作为来源正文身份；同一任务固定首次来源记录，并将差异幂等保存在 `source_metadata`，提取上下文和内存证据库均使用固定版本。正文、类型、URL、本地路径和定位仍不可静默改变。
- 仅对错误精确为旧版 `source/.../publication_date` 冲突、且通过任务隔离检查的质量阻断开放原任务续跑；其他质量冲突、跨任务历史污染、缺失或不兼容检查点仍拒绝恢复。
- 回归覆盖空日期、日期格式和日期值差异、标题差异、重复观察、重启、多任务隔离、正文/URL 冲突事务回滚，以及失败检索恢复时仅重放本任务搜索结果并使用原来源。
- 验证：完整后端回归 195 项通过（325.94 秒，`work/source-metadata-full-results.xml`）；补充原任务 API 续跑测试后专项 32 项通过（`work/source-metadata-final-results.xml`），成功节点不重复执行。只读检查截图任务确认通过隔离检查并允许续跑，保留原 5 个模型步骤、5 个流程节点和 4 个检索结果。未修改生产任务状态或调用真实模型/搜索。

### 任务数据隔离修复（2026-10-11）

- 移除跨任务历史财务事实查询与自动导入；成功单元、图检查点、检索/文档缓存均限定原任务。检索服务身份加入恢复输入指纹。
- 新任务在产生成果前保存带原 run_id 的隔离策略标记。旧真实任务含历史复用记录，或已经保存成果但缺少可确认的隔离标记时，拒绝自动/手动续跑及正式报告交付。原数据不删除，阶段导出保留并标明隔离问题，旧未标注快照不能绕过检查。
- 同一任务中，相同来源/证据/事实 ID 的内容或财务口径变更会被拒绝，事务保留原值；重述应使用新事实 ID 与版本。同一 ID 在不同任务中仍各自独立。
- 图检查点必须属于原任务与原公司输入。多次失败仍仅复用该任务输入完全一致且校验和有效的成功单元，失败/不确定结果不会当作成功结果合并。
- 新增测试覆盖同公司六种任务状态的隔离、三次结果重放、多次失败与不同输入、旧任务启动/续跑/报告/阶段导出门槛、缓存隔离和重复 ID 拒绝覆盖。测试使用独立数据库与 Mock HTTP。
- 验证：完整后端回归 182 项通过（346.35 秒），报告 `work/data-isolation-results.xml`；补充检查点归属、损坏单元和旧模拟指纹兼容测试后，隔离专项 21 项通过，恢复与隔离联合 31 项通过（`work/data-isolation-recovery-results.xml`）。JSON/ZIP/Markdown 阶段导出保留隔离状态与原因。验证期间未调用真实模型或搜索。

已成功提交、输入有效的单元可复用。供应商已处理但响应未落盘的请求仍可能重试；不保证任意外部请求恰好一次。保存失败会停止执行，不能把尽力写入的评估包当作恢复台账。

旧任务没有新的单元历史，不补造未保存的响应。旧真实任务还需通过上述数据隔离检查；无法确认隔离时只保留阶段成果出口，不继续使用旧图。旧规则检查点继续保持不兼容。graph.sqlite 缺失不会从头悄悄重跑，原阶段成果仍能导出。

本版暂未提供 changed-input 的自动局部失效重算、blocked 质量修复输入接口、completed/limited 的可选单格式补导出入口、供应商幂等键/响应查询、分布式租约及用户请求幂等键。上述功能不影响原配置下的中断/执行故障续跑；不得将它们描述为已实现。SQLite 会保留完整单元输出，磁盘占用随任务增长，后续清理须保留恢复所需版本并另行设计。
