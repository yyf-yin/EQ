# 个人工具：年报仅由用户提供

2026-10-15，真实固定表模式升级为 `fixed-slots-2`，采用 `user-annual-reports-1` 与 `uploaded-quarterly-periods-1`。固定财务字典仍为七区、133 字段，证券继续从 local-datasource 获取。新增季报／中报上传取数及季度槽；当年最新披露累计期间与上年同期核心数据必需，历史季度缺披露可留空，详见 [季度数据槽](QUARTERLY_DATA_SLOTS.md)。

## 使用

在初始页“添加文件”选择本次使用的公司年报，可以一并上传更正披露、研报和行业资料，然后开始研究。这个文件选择入口即本次指定清单；不再自动采纳本地目录中的年报，也不建立新的本地资料库。

每份文件上传后绑定本次研究。固定表财报来源只接受 upload；完整财年和业务范围识别只接收本公司上传年报，最新中期范围由程序从上传季报／中报识别。财务和债券只从本次财报文件提取。业务与行业复用同一份财报的定性证据，不重复按问题读取。

没有上传文件时，前端禁止开始，后端返回上传提示，不创建或排队任务。上传资料中没有本公司年报时，在研究范围识别前说明缺失，不调用模型推测年度和业务，也不寻找替代年报。

## 保留的检查

默认输入由本人准备，不评分材料质量，不检查来源权威性，不增加重复人工确认。程序只保留正常处理资料所需的检查：文件可读性、报告类型与公司/年度归属、原文位置、年度列、单位、合并/母公司/分部口径及数值与原文对应。

三年展示数据仍多取一个前序年用于同比；按实际原表或比较列覆盖判断，不机械要求四份文件。缺年度、缺字段和解析失败分别记录，说明对分析或计算的影响，不填零、不换渠道补年报。核心输入缺失仍按既有固定表规则保留成果并阻止依赖缺失数据的正式计算/交付。

用户提供的文件经过提取检查后锁定，成功结果在本次研究内复用，错误只修复对应失败项。更正披露也只能来自本次提供的文件，不自动下载新版本。

## 其它资料与恢复

业务、行业仍可做中性方向的有界 web 搜索。查询不安排公司年报检索；标题/摘要/链接已识别的公司年报结果在读取前排除，未标注资料读取后识别为公司年报也不纳入提取。行业协会、产业发展、市场统计等年度报告仍可作为行业参考。上传的其它公司年报可作为用户提供的行业参考，不能填入目标公司财务槽。

未采用的本地目录年报不会覆盖上传数据，也不影响本次研究的本地来源恢复指纹；上传原始文件仍沿用任务绑定和字节指纹。新的年报入口合同与提示进入兼容性检查，更新后重启服务并新建研究，旧成果保留。模拟模式继续使用合成资料；legacy 模式仅保留旧协议回归路径。
