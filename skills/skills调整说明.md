2026-10-06，按“行业研究与公司深度分析”交付目标完成本地调整。保留两套技能的 19 个入口名称、能力 ID、书籍出处和目录；同步修订 34 张路由能力卡，避免独立入口和备用入口规则冲突。

## 核心变化

| 问题 | 调整后的行为 |
|---|---|
| 行研混入股票推荐的前置条件 | 默认研究行业供需、竞争格局、公司经营、增长与财务；要求投资判断时再追加价格、隐含预期、催化和评级。 |
| 固定数量和概率阻断任务 | 历史长度、因素数量、第二来源、同事预审、情景概率等按机制和证据选择；数据缺口不阻止有依据的部分交付。 |
| 财务与估值口径错误 | 修正 EBITA、FCFF/WACC 与 FCFE/Ke、经营价值到股权价值桥接、NOPLAT、增长/再投资稳态条件；明确平均 ROIC 与新增回报的区别。 |
| 财务异常被机械定性 | 净利润/CFO 先检查符号与分母并做桥接；动机缺失不跳过审查，异常数量不直接对应造假结论或折价。 |
| 并购和资本运作算术不自洽 | 区分百分点、相对增幅、协同与成本，统一对价/价值口径并防止重复扣成本；同时比较现金流时点、风险与财富转移。 |
| 历史样本被套成通用规律 | 原书案例与出处移到按需背景；保留九类优势、八类增长、FaVeS 等思路，避免将美国历史统计、评级与人类工作配额当统一门槛。 |
| 研究计划被误报成已执行 | 事实、口述、预测与推断分开；生成访谈、外发或监控方案不代表动作已完成。 |

两个路由入口和六份概览/术语/索引已同步到当前规则；速查直接链接可执行卡片。独立 skill 未安装时，路由卡仍能提供方法。其他根目录蒸馏资料保留为历史背景，不能覆盖修订指令。

## 入口分工

行业范围与供需 → 关键经营因素 → 公司增长/竞争优势/财务质量 → 预测与风险情景 → 报告。需要投资价值判断时追加估值与市场预期。

`equity-valuation` 负责方法选择、价值桥接和估值交付；`valuation-multiple-traps` 负责倍数定义与可比校准；`roic-growth-value-core` 检查再投资经济性；`implied-expectations-reverse-dcf` 反推价格条件。按阶段组合，避免重复加载和重复计算；原有两套 router 不是所有任务的前置入口。
