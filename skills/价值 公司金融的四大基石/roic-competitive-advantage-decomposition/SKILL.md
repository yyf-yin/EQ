# 竞争优势、经济回报与持续性

1. 定业务、产品、区域与客户群；分部数据不足时标注合并近似。对齐同行税后经营利润、租赁/研发/商誉、期初或平均资本口径。
2. 可计算拆解：`ROIC = NOPLAT/收入 × 收入/投入资本`，即税后经营利润率×资本周转。价格/单位成本分析使用匹配单位与销量，不将单位价差直接除以公司总资本。
3. 将相对同行差异解释为价格溢价、单位成本或资本占用。原书九类是检索清单：创新、质量、品牌、客户锁定、定价纪律；商业模式、特有资源、局部规模、可扩展性。可有组合或其他机制；不在清单内应继续取证，不直接归因于会计或周期假象。
4. 用进入壁垒、替代、买方/供应方力量与竞争强度校验优势。给证据：净价/留存/复购、转换成本、当地密度、成本曲线、周转/良率等；说明替代解释、周期、资本基数与费用化造成的偏差。
5. 持续性检查竞争者反击、技术替代、专利/合同/资源期限、客户迁移和维护投入。品牌或软件不自动永久，资源优势也不必然短暂；历史分位与转移概率仅在样本匹配时使用。
6. 有收购时算含/不含商誉回报，并查支付溢价、经营改善及减值；两口径变化不足以单独证明内生回报或价值归属。

输出优势机制与量化证据、行业结构、周期/会计替代解释、持续期和中期回报区间、反证与缺口。多业务、金融和极低/负资本公司应采用适合的单位经济性与股权指标，不硬给 ROIC 分位。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
