# ROIC、再投资与增长价值

## 口径

- NOPLAT 是经营利润扣除经营相关税负；优先从调整后的 EBIT/经营利润桥接。从净利润起算时统一归属口径，加回税后净融资费用，剔除税后非经营项目，并调整相关税差；扣非净利润不自动等于 NOPLAT。
- 投入资本包含经营资产减无息经营负债，覆盖固定资产、经营无形资产/研发调整、租赁、营运资金及所选商誉口径；排除超额现金和非经营投资。列明期初或平均资本与期间匹配，分子分母对研发和租赁一致调整。
- `平均 ROIC = NOPLAT / 同期间匹配的投入资本`。含/不含商誉分别解释经营回报与收购价格影响；差异是调查线索，不单独证明并购毁灭价值。
- 新增长项目比较预期增量回报与项目相应资本成本。历史平均 ROIC 不能代替未来新增投资回报；效率改善既有资产带来的增长需单独拆分。

## 执行

1. 尽量拆业务/区域；披露不足用公司层面近似并说明混合业务局限。记录计算桥接、来源和必要估算。
2. 估资本成本的币种、风险、税后债务成本、股权成本及目标市值权重，给参数依据和敏感性，不固定美国历史 8%–10%。
3. 区分存量改善、内生新投资与收购，给新增回报和再投资范围。可估新增回报高于资本成本时增长可能创造价值，低于时可能损害价值；信息不足则为条件判断，不能按存量 ROIC 一票否决扩张。
4. 仅在经营利润增长和新投资回报稳定等假设成立时，使用 `IR = g / R`、`FCFF = NOPLAT × (1 − IR)`。R 是预期新增投资回报；假设新增与平均 ROIC 相等时注明。收入 g 仅在利润率等口径稳定时替代经营利润 g。IR 超过 100% 表示需要外部融资，不自动等于项目负 NPV。
5. 稳态经营价值 `V_op = NOPLAT_1 × (1 − g/R) / (WACC − g)` 要求 `g < WACC` 和匹配的永久稳态参数。高增长/回报变化显式分阶段；所有回报分支都给 IR/FCFF 或说明不可用。
6. 若要求股票价值，从经营价值加非经营资产、减债务及其他请求权，处理少数股东和稀释；不能把 V_op 当市值或把 V_op/NOPLAT 当 P/E。

## 输出

NOPLAT/资本桥接、平均与新增回报、g/R/WACC 参数、条件价值判断、投资率/现金流及敏感性。ROIC 或资本接近零/负时不机械套用稳定公式；融资、研发和政策风险用情景说明。
