# 业务组合、所有者协同与剥离

每项业务先估独立经营价值，再比较当前与候选所有者的可实现增量：共享渠道/技术、特有能力、治理、资本/人才和投入。归类仅帮助找机制，未归类不直接判总部无价值。

SOTP 对齐分部现金流、债务/少数股东、总部成本、税、分拆/交易成本与集团协同，避免把各段倍数相加当无条件价值释放。数据不足用范围，不虚构分部。

持有/出售比较未来经营现金流、改善能力、机会成本、净售价、治理/关联关系与执行概率。潜在买家数量按证据，不能强制 3–5 家；不是最佳所有者也需权衡成本和可行性才判断出售。

“业务对不同所有者价值不同”来自现金流/风险/成本条件，不能理解成完全没有可估价值。出售低倍数业务不会仅因剩余倍数较高就自动增值。

输出独立价值、所有者增量与证据、净交易效果、约束和条件结论；历史公告正回报、早卖高价或规模阈值不作为通用预测。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
