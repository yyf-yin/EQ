# 估值偏离、套利限制与危机机制

建立多情景的现金流/价值锚及不确定范围，检验价格隐含假设与经济约束。没有可信现金流锚时可报告极端相对估值，不给确定泡沫结论。

区分原先定价过度乐观、新信息、外部冲击与流动性挤压；这些可能同时发生，不能仅因下跌有外部冲击就排除泡沫消退。

检验借券、资金约束、保证金、流通盘、跨市场权利与渠道等套利限制；限制解释偏离可能持续，不是泡沫必需条件或回归时间表。实际交易制度按市场/日期核实，不沿用原书历史“不允许卖空”的概括。

另查短债/长资产错配、再融资、担保/传染与强制出售，区分价格波动与系统性偿债机制。

输出条件价值锚、偏离、替代解释、套利/融资约束及危机风险；不得用自身点估值当理性全信息的唯一真值，也不从偏离直接给做空/抄底时点。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
