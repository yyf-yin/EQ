# 债务、偿债与财务弹性

列有息债务、现金可动用性、租赁、永续工具、担保/保理/表外义务及未来到期表；区分控股股东质押与公司自身负债，说明传导路径，避免重复计入。

算净负债/适当经营利润、利息覆盖和偿债现金流，检查峰值分母、经营性资金需求、受限现金、契约及融资渠道。评级辅助判断，不能把美国 BBB/BBB+ 直接映射国内等级或作为所有公司的底线。

压力情景覆盖利润/现金流下行、利率变化、债务集中到期与新融资受限，比较现金、到期负债和最低经营投入。周期行业特别检查底部能否维持资产与投资。

比较税盾、困境成本、代理/融资约束和失去弹性的净影响，不套用固定“优化价值不到 10%”。返还现金前检查高回报投资、维持性投入与流动性储备；回购要区分财富转移与新增价值。

输出杠杆口径、到期与压力表、风险传导、缓冲与未知项。无到期数据标为无法验证再融资风险，仍完成可得指标分析。金融机构使用专属监管与资本框架。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
