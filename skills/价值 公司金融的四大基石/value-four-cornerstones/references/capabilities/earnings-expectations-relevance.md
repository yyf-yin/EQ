# 财报更新、预期修正与盈利质量

比较当期结果与当时可得一致预期/指引，核对样本和口径；同时检查未来经营假设、订单、利润率、现金流、资本开支和管理层指引是否改变。没有分析师修正数据时可用公开经营事实形成受限判断。

检查亮眼利润是否来自提前确认、压货、研发/营销透支、非经营损益或税务时点，给调整桥接，不把一次性与虚假现金流混为一谈。

书中盈余意外解释力低于 2% 属特定样本与窗口，不能推出所有单季财报不重要；波动可能包含信息、周期与融资风险，不能预设残差为零。

纯会计列报变化与经济变化分开：需检查现金税、契约、披露信息和行为后果，再判断基本价值。披露或指引制度按当地规则核实，不笼统判定给/不给指引好坏。

输出经营变化、预期证据、盈利质量、长期预测是否改变及反证；预测或估值变化要落到具体机制，不能因 beat/miss 本身机械升降观点。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
