# 增长来源、质量与天花板

1. 按可得数据拆收入增量：量、价、结构/汇率、新品类、客户/频次、地域、份额、并表。各项应能对总变化勾稽；交互项明确归属，避免既按量价又按客户再加一遍。来源未披露时用代理和区间，不伪装精确拆分。
2. 每项问谁受损、能否/愿否反击，以及复制、价格战、产能或监管约束。区分品类扩张与存量再分配；政策创造市场不等于没人受损或永远有高回报。
3. 以原书八类提出比较假设：创造新市场、提高现有客户购买频次、引入新客户、成长市场抢份额、补强并购、渐进创新抢份额、降价促销抢份额、大并购。再比较新增投资回报、资本需要、成功概率、持续性和已支付价格。创造新市场也可能高失败/重资本，大并购也可能正 NPV；不能只按来源标签排序定结论。
4. 做天花板算术：目标增长持续 N 年后的收入/销量、占市场份额、客户渗透、产能和所需资金。名义与实际增速、内生与并表分开；利润率变化时收入 g 不直接进入稳定 FCFF 公式。
5. 检查现有业务、近期可规模化项目与长期期权的储备、资源投入及失败条件；新行业参数未知时用市场规模/渗透/供给多情景，不因没有历史 S 曲线停止研究。
6. 输出增长桥接、竞争反应、投资经济性、天花板与增长假设区间及置信度。历史 5.4% 等数值属于特定样本背景，应用需本地匹配和来源校准。

经营增长预测不要求存在尚未计价的催化剂；判断新增增长是否创造价值使用新增回报与适用资本成本，不能机械套存量 ROIC。渠道压货和提前采购单列为时点/质量问题。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
