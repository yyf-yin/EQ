# 并购价值创造与支付溢价

1. 定买方/卖方视角、公告前基准、支付方式、融资和监管状态。现金支付、换股及混合交易的股东价值分配不同；先统一目标独立价值与价格的股权或企业口径。
2. 用五类原型寻找机制：绩效改善、过剩产能退出、市场准入、技术/技能获取、早期培育。清单不是排他证明；未归类可继续验证其他机制，泛称平台/国际化不足以证明协同。
3. 估目标独立价值 V0 与价格 P，市场价仅是有条件代理，不自动等于内在价值；溢价 `P−V0` 与溢价率使用同一基数。
4. 将增量税后协同、资本效率、现金税、整合投入和执行时间逐项估现值。税率/融资和折现口径一致，检查重复计入；给实现概率/延迟/失败情景，不把管理层协同目标当事实。
5. 在买方自身价值不受其他影响、现金支付且口径一致的简化条件下，`买方净价值 = V0 + 净协同现值 − P − 尚未计入的交易/融资/整合成本`。净协同已扣成本时不能再次扣；换股需评估对价实际价值及原股东/新股东的稀释与共享协同。
6. 所需净协同率等于溢价率，仅在同基数及其他成本已计入时成立；额外成本提高门槛。净价值对买方市值的比例是重要性尺度，不是承诺股价涨幅。交易未确定完成时分别呈现完成/失败状态和估计概率。
7. 验证运营能力、竞买压力、历史收购回报、治理/关联关系与商誉；EPS 增厚只说明会计结果，不能替代价值算术。小额补强收购缺逐笔数据时做累计投资与经营回报分析。

## 自洽示例（修订示例，非原书核实引文）

V0=10 亿、P=13 亿、净协同现值=4 亿、无其他成本，买方净价值=1 亿；溢价率=30%。原蒸馏“独立价值 50”与该算例不一致，已移除，原书数字待核。

收入不变时营业利润率 6%→9% 为提高 3 个百分点、利润增长 50%；30%→45% 为提高 15 个百分点、利润增长 50%，成本率 70%→55% 相对下降约 21.4%。这仅是利润算术，价值是否增长 50% 还依赖税、资本和持续性。

输出独立价值、对价与融资、净协同/成本桥接、状态情景、股东价值分配和关键反证。私有标的缺数据时用代理范围；协同现值占价款较大不单独证明正 NPV。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
