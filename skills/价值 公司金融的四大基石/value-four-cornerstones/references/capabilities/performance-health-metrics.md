# 经营结果与前瞻健康指标

摆出收入、利润率、资本回报和现金流，再问结果来自提效、产品/客户改善还是透支。

检查净价与份额/复购、费用化加资本化的研发总投入、营销与获客、渠道库存/终端销售、维持性资本开支和资产状态。费用下降可能是效率提升，也可能透支；需比较证据，不能自动扣分。

按行业选择少量领先指标，记录来源、领先机制、可观测性、时间和反证。可包括留存/满意度、单位成本、产品储备、良率、资产更新和关键人才，不编造无法获得的指标。

分部/区域/客户批次可用时下沉；只有合并披露时结合外部指标与代理并说明局限，不要求 20–50 个核算单元。EPS 指引的存在或取消不是通用质量信号，先区分当地强制披露与自愿管理目标。

输出财务结果、达成方式、健康指标和持续性判断及缺口；无法验证的持续性保留条件结论。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
