# 股东总回报的可复算归因

固定窗口、普通股/股息再投资、拆分/送转、币种、每股口径与基准；优先使用一致的总回报序列。股息若已计入复权序列，不再额外加收益率。

股价与 EPS/PE 均为正且可比时使用 `P1/P0=(EPS1/EPS0)×(PE1/PE0)`，将增长与重估贡献用对数等可复算方法分开；有亏损、口径变化时换成价值桥接或粗分，不硬凑倍数。

解释 EPS 时拆收入、利润率、股份/融资等变化，明确交互项与分解顺序。书中七项框架可作机制清单，但未获得完整计算式时不声称复刻七项百分点贡献；盈利收益率不等于实际派息收益率，累计资本开支不能直接作为股价回报负项。

如比较管理层表现，使用适当同行与经营结果、风险控制，不能仅凭相对 TRS 证明能力。预期重估/杠杆的贡献不宜机械外推，是否再次出现需新的驱动证据。

输出总回报、复算公式、业绩/估值/分配及交互或残差、局限与可持续性讨论；不使用任意残差补全叙事。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
