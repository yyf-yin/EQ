# 倍数选择、盈利正常化与同行校准

1. 定义指标。非金融经营比较可考虑前瞻 EV/EBITA；`EBITA = EBIT + 相关摊销`，保留折旧；`EBITDA = EBIT + 折旧 + 摊销`。并购无形资产摊销通常在 EBITA 中加回；若刻意保留某项成本，另命名调整 EBIT 并桥接，不能称作标准 EBITA。
2. EV 桥接普通股市值、债务、少数股东/优先请求权和非经营资产，租赁/养老金与分母一致。股权指标配股权市值。P/E 受资本结构影响，杠杆变化可升或降 P/E，方向取决于收益与融资成本等条件，不是“负债越高 P/E 必然越低”。
3. 分母用明确预测期或 TTM，剔一次性与非经营项目，统一会计、研发、租赁及周期；可持续盈利调整必须有来源和桥接。缺一致预期可用自有预测并明确标记，缺前瞻输入用正常化历史区间。
4. 选经营机制、增长、回报、风险、利润率和资本强度相近同行。g×ROIC 网格辅助分组；没有 3–5 家真正可比者时少数同行也可用，不硬凑样本。
5. 对倍数差异分别讨论增长、回报/再投资、资本成本、治理/流动性/会计和资本结构。EV 指标不再机械加入已剔除的融资影响；若不能识别各项定量贡献，用定性或模型情景，不能把残差直接叫错杀。
6. 周期极值使用中周期盈利/现金流、资产或重置成本等合适方法；银行保险用专属口径。亏损/近零分母用场景 DCF 或有经济映射的经营指标，不能以用户数代替未来现金流解释。

输出指标定义与调整桥接、同行选择、预测日期、折溢价解释和区间。未解释差异意味着需要验证，不自动证明市场错误；跨市场价差先核实权利、会计、流动性和可投资渠道。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
