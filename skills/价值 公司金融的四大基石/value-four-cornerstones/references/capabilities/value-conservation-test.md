# 资本运作的经济价值与财富转移

1. 写被宣称的价值及受益对象：经营资产、全部资本提供者、普通股股东或继续持有者；固定交易前后比较边界。
2. 比较未来现金流金额、时点、风险、折现条件和交易成本。只有在这些均未变化时，仅改账面表示或现金流所有权不增加总体经济价值；相同未折现总金额不保证相同现值。
3. 找具体机制：收入/成本协同、资本效率、税盾、困境成本、融资约束、代理问题/管理行为或风险分配。量化能量化的净效果；缺披露输出无法验证，不将“未找到证据”说成确定无价值。
4. 会计变化先检查现金税、合同/契约和经营行为后果；纯列报变化本身不改经济价值。真实补助或处置现金流计入对应资产/情景，另分持续性，不能因非经常性一律抹掉。
5. 回购检查资金来源、价格相对价值、注销/库存股/再发行、激励稀释及资本配置。低估回购可在卖出与留下股东之间转移财富；EPS 增厚不自动创造总体价值，也不能预言 P/E 必然精确抵消。
6. 证券化/结构融资列费用、追索/担保、期限错配与风险承担者。整体风险可能重分配，融资约束也可能变化，不能仅因打包就说风险消失。

输出总体价值、融资/风险变化、财富转移、会计指标和短期价格反应的分开判断。并购需要净协同与支付价格的定量分析；经济价值改善与市场重估时点是不同问题。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
