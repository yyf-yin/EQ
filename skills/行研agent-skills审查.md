## 2. 对你的目标最有帮助的部分

这些内容能够把研究从“信息汇总”推向“解释机制并验证判断”：

1. **供需与公司预测交叉校验**：把各公司份额、销量、产能与行业总量放在一起，暴露不可能同时成立的增长假设。
2. **增长来源拆解**：区分品类扩张、提价、抢份额、并表与渠道压货，再检验竞争反击和市场天花板。
3. **优势到财务结果的映射**：把品牌、规模、转换成本等叙事落实到价格、成本、资本周转与优势持续性。
4. **数据与证据纪律**：对齐名义/实际、季调、时期、会计口径；保留证据来源，区分事实、他人观点和自己的推断。
5. **可证伪与动态跟踪**：明确哪些新数据会改变结论，而不是每次更新重新写一篇泛泛的报告。
6. **透支检查**：利润和 ROIC 改善时，继续检查研发、营销、渠道与维持性资本投入，识别财务漂亮但经营健康恶化的情况。

其中，第 1、2、3、6 项最贴合行业研究与公司深度分析；市场分歧、催化剂和目标价纪律适用于需要进一步讨论投资价值的任务。

## 4. 必须先修的计算与流程问题

以下“必须先修”指：启用受影响模块之前完成，不必因此阻止其他已修订模块接入。

### 4.1 EBITA 定义写反，杠杆对 P/E 的方向也被写成恒等式

位置：[valuation-multiple-traps/SKILL.md:84](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/valuation-multiple-traps/SKILL.md:84>)，以及同名参考卡、description。

当前写着“EBITA 对并购形成的无形资产摊销不做加回”，这与通常的 EBITA 定义相反。EBITA 加回相关摊销但保留折旧；EBITDA 再加回折旧。如果采用特殊调整口径，应另行命名并明确桥接。例：EBIT=100、相关摊销=20、折旧=30，则 EBITA=120、EBITDA=150。[麦肯锡的倍数估值说明](https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/the-right-role-for-multiples-in-valuation)

同文件第 39 行称“负债高的公司 P/E 必然低”。这不成立：方向取决于经营收益率、税后债务成本等条件，不能把一个案例推广成数学恒等式。上述麦肯锡文章也明确讨论了杠杆可能抬高 P/E 的条件。建议保留“P/E 受资本结构影响”，删除固定方向判断。

### 4.2 逆向 DCF 缺少企业价值到股权价值桥接

位置：[implied-expectations-reverse-dcf/SKILL.md:80](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/implied-expectations-reverse-dcf/SKILL.md:80>)。

当前要求固定 WACC 与 ROIC，令模型价值等于当前市值。若模型使用 FCFF/NOPLAT，得到的是经营资产价值；不能直接与股票市值相等。应先明确现金流口径，再处理债务、现金、非经营资产、少数股东及其他资本请求权；使用 FCFE 时则匹配股权成本和股权价值。[CFA Institute 的自由现金流估值说明](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

已复算一个稳态反例：NOPLAT₁=100、ROIC=20%、WACC=10%、g=4%，经营价值约 1,333.33；假设仅有净债务 300，则股权价值约 1,033.33。把后者错误代入经营价值公式，反解 g 仅为 **0.625%**，而不是 4%。这会把口径错误误判为“市场预期悲观”。

还应说明：反解并不唯一，结果是条件于 WACC、优势持续期、利润率、再投资及终值假设的参数组合，不是直接观察到的真实市场预期。两个单变量反解点不足以自动构成完整等值曲线。

### 4.3 财报审查会跳过核心检查

位置：[equity-financial-forensics/SKILL.md:74](C:/work/PROJECTS/创建skill/skills/证券分析师的最佳实践指南/equity-financial-forensics/SKILL.md:74)。

“六类压力源全无则跳到第 4 步”会跳过报表和报表外信号审查。没有发现压力源，不能证明没有压力或没有异常；而且这张卡本身也用于审查已发现的利润与现金流背离。

建议：动机仅影响调查优先级；最低限度的盈利—现金流桥接、应收存货、收入确认、审计与披露检查始终执行。第 81 行“超过 3 个旗标就不必继续细查”也应删除：多个指标可能来自同一正常交易，需要解释与去重，不能直接以计数决定折价。

### 4.4 价值驱动倍数被误标为 P/E

位置：[market-valuation-drivers.md:68](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/value-four-cornerstones/references/capabilities/market-valuation-drivers.md:68>)。

公式 `(1 − g/ROIC)/(WACC − g)` 来自经营价值除以下一期 NOPLAT，通常不是股权市值除以净利润的 P/E。应标为相应经营价值倍数；推 P/E 需经过股权价值与净利润桥接。净债务为零且净利润等于 NOPLAT 等特殊条件，也必须说明。

同卡同时把“实际增长 + 通胀 + 派息收益率”用于长期回报，却又称该总和为实际回报。加通胀得到的是名义口径；实际回报需另行扣除通胀或做精确换算。

### 4.5 ROIC 计算与增长决策的口径不足

位置：[roic-growth-value-core/SKILL.md:79](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/roic-growth-value-core/SKILL.md:79>)、[NOPLAT 补充口径:112](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/roic-growth-value-core/SKILL.md:112>)；`roic-competitive-advantage-decomposition` 的公式与执行步骤。

- 从扣非净利润出发计算 NOPLAT，必须桥接税后净融资费用，并统一税务、非经营项目和少数股东口径；只剔除非经常项会留下融资结构污染。
- 投入资本应说明期初或平均口径、经营性无形资产、租赁资产与负债的一致处理、商誉调整及非经营资产排除。
- `(价格−成本)/资本` 是简化直觉，不能把单位价格与公司总资本直接相除。可计算拆解应使用 `NOPLAT/收入 × 收入/投入资本`，并与税后口径一致。
- 判断新增增长是否创造价值，应看新增投资的预期回报，不能机械套用存量平均 ROIC。平均 ROIC 很低的公司仍可能有高回报新项目；平均 ROIC 很高的公司也可能扩张到低回报领域。[Damodaran 关于平均与边际回报的说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/growthrates.htm)
- `IR=g/ROIC` 需说明稳定回报等假设；收入增速只有在利润率等口径稳定时才能直接映射到经营利润增长。永续公式要求 `g<WACC`；高增长期应显式分阶段。
- ROIC≈WACC 或低于 WACC 的分支目前跳过投资率计算，最后却要求输出投资率；应补齐分支，无法估计时明确标记。

### 4.6 并购算例存在直接可复算的不一致

位置：[ma-value-creation-assessment/SKILL.md:41](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/ma-value-creation-assessment/SKILL.md:41>)、[收购算例:59](<C:/work/PROJECTS/创建skill/skills/价值 公司金融的四大基石/ma-value-creation-assessment/SKILL.md:59>)。

- 利润率从 6% 到 9%，是增加 3 个百分点、利润相对增加 50%，不是“边际利润增 9%”。
- 从 30% 到 45%，是增加 15 个百分点、相对增加 50%；成本率从 70% 降到 55%，相对降本约 21.4%。应区分百分点、比例与终点水平。
- “B 独立价值 50，付 13 亿，溢价 30%”口径不一致；13 亿对应 30% 溢价的基数应为 10 亿。没有原书全文，需回源确认正确数字，不能直接猜改。
- 成本节约现值占收购价较大，不足以单独证明交易创造价值：仍要比较目标独立价值、支付价格、净协同和交易/整合成本。

### 4.7 回归模块缺少预测有效性验证

位置：[regression-forecasting.md](C:/work/PROJECTS/创建skill/skills/证券分析师的最佳实践指南/equity-research-best-practices/references/capabilities/regression-forecasting.md)。

当前以散点图、R²>80%、p<0.05作为主要门槛，并建议加滞后直到残差模式消失。它可能放过趋势引起的伪回归和过拟合，也可能错删有预测价值的变量。

建议补时间顺序的样本外验证、朴素基准比较、数据发布时间与修订处理、稳定性/结构变化及必要的趋势和残差诊断；禁止为了达标无限增加变量。散点图与显著性不能单独证明预测能力。[Hyndman 与 Athanasopoulos 的预测变量选择说明](https://otexts.com/fpp3/selecting-predictors.html)

## 5. 会降低 Agent 实用性的规则

### 5.1 证券推荐规则侵入行业研究

`equity-key-factors` 要求因素未被 price in、有投资期限内的催化剂；`equity-report-writing` 要求首页回答买还是卖，新颖性不足就停止写作；多个入口将宏观变量排除为主要因素。

这些条件可用于股票推荐，却不适合作为行业研究和公司深度分析的通用门槛。已经被市场充分认识的油价、汇率、政策、资本开支，仍可能是理解行业与公司的关键经营变量。行业入门、财报更新、竞争格局梳理，也不一定需要独家分歧才能交付。

建议设置两种模式：

- **经营研究模式**：识别行业机制、公司经济性、事实证据和未知问题；不强制目标价、市场分歧或短期催化剂。
- **投资判断模式**：在经营研究基础上，追加价格、预期差、催化剂与上下行条件。

### 5.2 历史经验被升级为通用硬门槛

具体例子：行业至少有 3 家退出公司；至少两个经济周期；候选因素至少 8 条、最终不得超过 4 条；单个来源不足就替换因素；基准概率至少 50%，二元事件各 50%；深度报告固定 13 页；必须有同事看过提纲才能写正文。

建议改成按任务深度和数据可得性决定的默认建议。两个结果不等于等概率；没有同事可审阅时可以完成带待复核标记的草稿；来源暂时不足时应保留假设与缺口，不能把“未验证”改写成“不是重要因素”。监管财报等权威原始记录也不需要为每个科目虚构第二个独立来源；关键推断才需要适当交叉验证。

应保留的硬约束是：不编数据、不混口径、标记推断和缺口、不把异常直接指控为造假、模型假设可追溯。其他数量、篇幅、时长规则应接受任务配置。

### 5.3 新行业分支跳过了最重要的供需分析

位置：[equity-industry-analysis/SKILL.md:82](C:/work/PROJECTS/创建skill/skills/证券分析师的最佳实践指南/equity-industry-analysis/SKILL.md:82)。行业不足 5 年就跳过第 2–4 步，其中第 2 步包含供需模型。历史不足只限制长周期回溯，不妨碍分析当前需求、有效产能、供给建设周期、市场份额与单位经济性。

建议保留现状供需和情景预测，把历史周期、长期财务基准与表现归因改为可选，并记录代理变量及置信度。

### 5.4 停止点与外部动作没有适配 Agent

联系 IR、同事书面确认、季度换血、日历持续监测、告知并披露伦理决定等，是人类工作流。对 agent 应分别定义：生成计划、分析已有材料、调用已授权工具、交给人执行。没有工具或授权时，输出待执行事项即可；不能假装完成，也不能让其阻止其他研究工作。

`equity-source-and-interview` 把“引导性提问”和“未遭反驳”作为合规取数工艺，需要重写：问法和报告措辞不改变信息性质，未遭反驳也不构成确认。CFA 的马赛克原则针对公开信息与非重大非公开信息的分析组合，而不是把已获得的重大非公开信息拆小或换名使用。[CFA Institute 的实际案例说明](https://blogs.cfainstitute.org/blog/2019/08/15/ethics-in-practice-security-investment-information-case-for-week-of-12-august/)

### 5.5 旧统计与作者局限写在不同位置，前者却更强势

例如：80% 的公司价格合理、P/E 回归 15 倍、长期实际回报 6.5%–7%、盈余意外解释力低于 2%、投资级评级底线。虽然文末已有作者局限与 A 股提示，但入口原则和执行步骤仍要求直接套用。

建议给历史统计标记样本、期间、口径、来源和适用范围，放入背景参考；运行时只在相关且完成本地校准时使用。尤其不能把“80% 合理”当作未经验证的部署先验，或把 WACC 当作股票持有人的预期回报。当前市场制度、会计规定和披露要求还需要按实际市场和研究日期核查。

### 5.6 价值守恒缺少风险与时点条件

“现金流总额没增加就不创造价值”需要限定现金流时点、风险和折现条件。相同金额的现金流在不同时间与风险下，现值可以不同。融资结构也可能改变税盾、困境成本、代理问题和经营行为。

保留反金融工程幻觉的追问，但输出至少区分：经营价值、融资/税务/风险变化、财富转移、市场短期重估。政府补助或资产处置应先区分是否真实现金流与是否可持续，而非一律删除真实价值。

## 7. 建议的接入结构

以研究任务而非书名组织跨书路由，保留书名作为来源元数据。不要要求 agent 每次先读两个整书入口。

建议顺序：

1. 确认研究对象、市场、截止日期、交付深度与问题。
2. 建行业边界、供需与产业链；梳理关键经营变量。
3. 汇总证据，检查口径、来源独立性与数据缺口。
4. 拆公司增长来源、优势来源、单位经济性与经营健康。
5. 必要时建经营预测和压力情景；复核行业总量与公司份额约束。
6. 用户需要投资价值时追加估值与隐含预期。
7. 形成结论、反证、局限、待验证问题及跟踪指标。

第一批启用：`equity-industry-analysis`、改写后的 `equity-key-factors`、修正后的 `equity-financial-forensics`、`growth-quality-ladder`、修正后的 `roic-competitive-advantage-decomposition`、`roic-growth-value-core`、`equity-forecast-modeling`、`equity-report-writing`。同时将信息中心、研报筛选、经营健康和财务弹性四张卡接入明确的按需路由。

两个现有路由写着“每次任务最多 2 张能力卡”，会妨碍完整深度研究。建议改为按阶段加载相关内容，避免同时塞入全部卡片；整项任务不设置 2 卡硬上限。

各模块共用最小交接字段：

`研究对象 / as_of / 指标期间 / 指标与单位 / 会计和币种口径 / 证据位置 / 来源类型 / 实际或预测 / 假设 / 结论 / 反证 / 置信度理由 / 数据缺口 / 下一步`

证据位置应能回到文件页码、表格、原始网页或具体纪要段落；置信度不能只写一个百分数。模型输出应附公式与输入，不只附解释。

将原文引述、历史案例、双语触发示例和详细统计放入参考材料；入口保留触发边界、关键执行规则、交接字段与参考链接。压缩的目标是减少重复和无关约束，不是追求任意行数。

当前未发现可执行的建模/取数脚本。这些 skills 能提供方法，却不会自动赋予行情、财报数据库、专家访谈或监控能力。后续确有重复计算需求时，再补可靠的口径转换、DCF、敏感性和约束校验脚本。

实际接入还需确认目标 agent 是否能发现书名目录下的嵌套 skill，以及只安装部分入口时能否访问对应参考卡。当前目录结构本身不能证明它们会被自动发现。

## 8. 现有测试能说明什么

证券研究包有 **63 条触发用例**；本次未在该包中看到与之配套的运行结果。价值包有 **60 条已报告触发用例**、结果记录与压力测试报告。价值包报告的 100% 主要说明在其用例中选择了预期入口。

其盲测输入是 name、description 与 prompt，输出为 selected_skill 和理由；这不能验证模型计算、证据处理、正文停止点或最终报告质量。现有测试分别局限在同书入口之间，尚未覆盖两个包同时提供时的跨书竞争。报告也说明每条只运行一次；一条不符预期的题目修改后复测，不应视为冻结测试集上的独立结果。

可保留现有触发测试，但它们不构成“接入会改善行研”的证据。

建议用相同原始材料，对当前 agent 与加入修订 skills 的 agent 做冻结任务对照，至少覆盖：

| 用例 | 应验证的实际行为 |
|---|---|
| 不足 5 年的新行业，只有近期产能和需求数据 | 仍能做现状供需与情景分析，不跳过核心研究 |
| 单一权威原始披露，暂无第二独立来源 | 如实引用记录、标记推断缺口，不虚构第二来源或拒绝全部任务 |
| 没有显性压力源，但应收与收入增长背离 | 执行财报检查，不从第 1 步直接跳过 |
| EBIT、折旧与摊销给定的同行比较 | 正确计算 EBITA/EBITDA；不武断断言杠杆必压低 P/E |
| 同经营现金流、不同净债务的两个公司 | 正确桥接经营价值与股权价值，解释隐含预期 |
| 存量 ROIC 低、新项目预期回报高 | 分开存量与新增投资，不机械拒绝增长 |
| 已知二元事件概率明显不对称 | 使用证据支持的概率，不默认 50/50 |
| 只要求行业入门报告，无股票推荐 | 完成交付，不因无催化剂或买卖结论停写 |
| 两个共同趋势序列，样本内 R² 很高 | 识别伪回归/过拟合风险，检查样本外能力 |
| 同时要求增长来源、竞争优势和财务预测 | 能跨书按阶段组合，不因最多 2 卡而遗漏步骤 |
| 公告只有 EPS 增厚，协同披露不足 | 区分会计增厚与经济价值，保留无法验证结论 |
| 专家未回答敏感问题，只有“未遭反驳” | 不把沉默当确认，不把换问法当作信息性质变化 |

对照评分重点：事实准确、来源可追溯、机制解释、计算与口径、反证、数据不足时的有效交付、实际用时和上下文成本。评审时隐藏版本来源，不按章节数、篇幅或是否重复技能术语评分。

**接入决策：保留这套蒸馏成果；先修计算与流程错误，再完成行业研究适配和跨书路由，最后用真实材料验证增量。** 最大价值来自它们能否稳定约束研究中的错误，而不是 agent 是否引用了书中的框架名称。
