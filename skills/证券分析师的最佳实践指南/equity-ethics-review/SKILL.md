# 信息性质与利益冲突审查

1. 固定事实、拟议行为、研究目的、适用市场/机构和已知规则。区分索取/收到信息、内部分析、形成推荐、交易及对外传播；不把这些行为混成一项。
2. 检查信息是否公开、重大、受保密义务或使用限制，及其来源与取得方式；检查持仓、客户、投行、礼物或管理层关系是否影响研究。
3. 对候选行为按合法、机构规则、透明、合法利益、审慎和适用伦理规范检查。电视/纪律委员会/十年/楷模测试是辅助思考，不替代实际规则或直接决定法律责任。
4. 将可执行分析、需机构复核、应停止的具体动作分开。疑似重大非公开信息停止相关索取和使用，不能通过改问法或拼图“洗白”；保留不受影响的公开研究。
5. 输出事实、规则来源与日期、冲突/信息判断、理由、未知项及下一步。需要告知同事、披露或回避时可先形成草稿/建议；不得声称已通知、回避或对外披露，除非实际动作已获授权并完成。

核心纪律：不为既定目标价倒改预测，不隐瞒已知重大错误和风险，不把他人观点或研究推断说成确认事实。妥善处理冲突后能否继续研究按实际规则决定，不笼统拒绝所有相关分析。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
