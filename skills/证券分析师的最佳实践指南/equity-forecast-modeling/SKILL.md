# 财务预测、情景与模型检查

## 执行

1. 明确预测用途、期间、频率与关键经营变量。行业供需和证据检查可用时作为输入；允许从已有可信材料直接建模，缺口单列。
2. 将输入/假设、计算、输出分离，标记来源和版本，避免在计算区藏业务假设。按任务建立收入、利润、现金流及必要的资产负债表和分部模块，不删除维持会计勾稽所必需的科目。
3. 按量×价、产能×利用率、客户×客单价等机制预测，检查份额、市场规模、成本、营运资金、资本开支、融资和股本稀释。历史颗粒度服务于季节性和验证，不固定两年季度化、表格行号或未来/历史耗时比。
4. 用关键变量构造一致的情景。基准/乐观/悲观是常用呈现，事件结果可设二元或多元；概率有依据才赋值并相加为 1，不因二元就设 50/50，也不强制基准占 50%。概率未知时用条件情景和敏感性区间。
5. 检查情景内部资源约束：价格、销量、份额、资本投入和回报不能各自独立取最优；量化关键敏感度。区分场景对比与概率加权期望值。
6. 核对季度与年度、报表平衡、现金变化、单位、符号和币种。任何增长/利润率拐点说明可验证成因；缺证的作为低置信度情景，不混入确定性基准。
7. 有市场预测时比较样本、时间和口径；没有一致预期或私下数字时如实说明，不能编造“悄悄话数字”，也不阻止经营预测交付。

## 输出

假设与证据表、预测与勾稽结果、情景/敏感性、失效条件和缺口。Python 与 Excel 均可；模型错误先修复，无法解决的输出范围受限。原书 AEIOU 的 A/E 转换缺失仍待原书核对，不补造释义。统计模型需样本外验证，不能以高 R² 替代预测有效性。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
