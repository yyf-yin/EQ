# 投资主张、预期差与催化剂

## 执行

1. 明确标的、研究期限与所需结论，先研究再决定方向，不强制预设买入或卖出。
2. 重建可观察市场预期：一致预期的期间、样本、发布日期、分布与价格隐含假设。公开预测未必等于真实定价；没有可靠私下预期就记录未知，不编造或索取敏感数据。
3. 写可证伪主张：“市场可观察预期 X、研究判断 Y、差异来自 Z”。FaVeS 的 F=预测、V=估值、S=心理；a/e 不构成维度。用证据检验优势，不能只用“市场短视”解释。
4. 若走 S 通道，按可观察持仓、交易与消息反应分析，不凭性格分类推定持有人心理。F/V 主张无需强制补心理画像或下一批买家。
5. 分开关键经营驱动与价格催化。记录催化的机制、可预期程度、时间窗口与失败风险；宏观变量重要但不可预测时用情景，不当作已知催化。长期观点可缺少短期事件，但要注明资金占用和兑现不确定性。
6. 比较估值区间、下行风险、替代解释与机会成本，给反证和更新条件。优势证据不足或不可兑现时结论可为观察、不形成推荐；继续交付已完成的经营研究。

## 输出

研究主张、FaVeS 通道、预期证据、上下行、催化/兑现条件、反方证据与结论。仅因熟悉公司、低倍数或股价上涨不足以升级推荐。价格变化本身不构成修改假设的依据；无可交易分歧不等于行业研究无价值。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。
