# 回归预测的验证与失效条件

1. 明确预测对象、可用时点、期限和朴素基准。只使用预测时已发布的数据及当时版本，防止使用未来修订或未可得的解释变量。
2. 对齐序列口径，检查季节性、共同趋势、异常、结构变化与缺失。必要时差分、去趋势或使用有理论支持的协整方法；共同上涨可能造成伪回归。
3. 散点图帮助理解，但单变量无明显关系不能直接排除多变量条件关系。机制与数据规模决定候选变量，检查共线性。
4. 按时间顺序留出/滚动验证，比较样本外误差和朴素预测，记录验证窗口及重复选择导致的偏差；不能用随机打散泄漏未来。
5. 查残差自相关、异方差和参数稳定性，调整须有机制/验证依据。R² 与 p 值作诊断，不是固定 80%/0.05 的准入门；统计显著不保证可预测，非显著也不能直接认定成本固定。
6. 复杂度按样本和样本外结果受约束，不为消除残差无限加滞后。预测未来解释变量本身也有误差，纳入区间。

输出模型用途、输入可得性、样本内与样本外结果、基准对比、残差和失效条件。样本短或无法验证时交付探索性分析/条件情景，不宣称模型经验证或把回归当因果证明。

## 证据与交接

保留研究对象、市场与截止日期、指标期间/单位/币种/会计口径、来源及页码或链接，区分实际值、他人预测和自己的假设；输出结论、反证、置信度理由、缺口与下一步。权威原始披露可以作为事实来源；重大推断按重要性寻找独立证据，转载同一消息不算第二源。资料不足时交付可支持的部分并标记未验证，不虚构数据或执行结果。

相邻能力用于分工；未安装时沿用本卡方法、记录缺口，不因缺少其他 skill 而拒绝整个任务。只在当前任务需要时读取背景材料；书中历史统计与建议数量不作为当前市场的通用阈值。
