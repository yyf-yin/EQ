# 指标与执行术语（行研适配）

| 术语 | 执行定义 |
|---|---|
| 关键因素 | 对需求、利润、现金流或风险有因果意义的驱动；投资任务另查预期差与催化。数量与阈值按任务选择。 |
| 催化/预期差 | 有证据的可能兑现机制/相对可观察市场假设的差异；缺数据标未知，不阻止经营研究。 |
| NOPLAT | 经营利润扣经营相关税负；与融资、非经营收益及税差作桥接，不等于扣非净利润。 |
| 平均 ROIC | 同期 NOPLAT/匹配投入资本；研发、租赁和商誉口径一致，和新增回报 R 分开。 |
| 新增回报 R | 新投资产生的预期增量经营回报，用于比较项目资本成本和估再投资需求；历史平均 ROIC 只是可能的代理。 |
| 投资率 IR | 稳定回报等条件下 IR=g/R，g 为经营利润增长；超过 100% 表示需要外部融资，不自动等于负 NPV。 |
| 经营价值 V_op | FCFF/WACC 的价值；稳态可用 NOPLAT_1×(1−g/R)/(WACC−g)，需 g<WACC、稳定参数。V_op/NOPLAT 不是 P/E。 |
| 股权价值/EV | 总普通股价值与经营 EV 需桥接非经营资产、债务、少数股东等；不能用流通市值代替总市值，现金不能重复扣加。 |
| FCFF / FCFE | 分别匹配 WACC / 股权成本 Ke；现金流与资本请求权、币种、税和时点一致。 |
| EBITA / EBITDA | EBITA=EBIT+相关摊销，保留折旧；EBITDA 再加回折旧。调整项明确桥接，不能错称指标。 |
| P/E | 普通股价值/归属普通股利润，需同口径。杠杆方向依条件，不能替代经营价值倍数。 |
| 现金转化异常 | 净利润与 CFO 差异是调查线索；检查符号/零分母与营运资金等桥接，不用固定比率定罪。 |
| 情景 / 概率 | 条件假设与结果不同于加权期望值；概率有依据才赋值，不默认 50/25/25 或二元 50/50。 |
| 检疫旗 | 待核实异常，不是欺诈结论；个数不直接对应估值折价。 |
| 马赛克分析 | 基于合法可用的公开及非重大非公开信息推断，遵守来源限制；改问法和未遭反驳不等于合法或确认。 |
| FaVeS / ENTER / CASCADE | 原书的推荐/表达检查思路；按当前能力卡适配使用，不作为经营研究或报告交付的前置硬门。 |
| 并购净价值 | 统一口径后比较独立价值+净协同−对价−尚未计入成本，成本不重复扣；换股另查股东价值分配。 |
| 价值守恒 | 区分总体价值、财富转移和结构变化，比较现金流数量、时间、风险、成本与融资约束。 |
| TRS | 股东总回报，明确分红再投资/拆分/股本/币种；复权序列不能再次加分红收益率。 |
| 实际/名义回报 | 实际回报=(1+名义回报)/(1+通胀)−1，不能把含通胀的名义结果称实际回报。 |

书中专用词和历史引文需要时查各能力的背景材料；本表用于统一操作口径。详见 [方法速查](cheatsheet.md)。
