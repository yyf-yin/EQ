# 证券分析师的最佳实践指南：行研使用概览

本套保留原书出处，执行规则按行业研究与公司深度分析适配。

先明确范围、截止日期和证据；建立行业供需与产业链，再分析公司增长、优势、回报、财务质量和健康指标，最后做自洽情景与报告。只有任务要求投资判断才加入价格、隐含预期与推荐。

小任务直接调用相关能力；完整任务按阶段加载，不要求一次读全部卡，也不限制整项任务最多两张卡。资料不足交付可支持的部分、条件判断和取证缺口。两本书中的相邻方法互补：预测负责经营路径，ROIC 检查再投资，估值负责价值桥接，逆向 DCF 检验价格条件。

原书历史数量、美国市场统计、情景概率和人类团队分工不作为 agent 的统一硬门。当前计算口径见 [术语](glossary.md)，方法入口见 [速查](cheatsheet.md)，案例及章节在各卡的背景链接中。
